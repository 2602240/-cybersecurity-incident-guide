# SOC Incident Response & Phishing Awareness Guide

## Overview
This repository contains standard operating procedures, triage checklists, and incident reporting templates for the Security Operations Center (SOC) at Zulu Global Inc.

## Files Included
- `README.md` - Project overview and usage instructions.
- `incident_checklist.md` - Step-by-step triage checklists for Phishing, Malware, and Social Engineering.
- `incident_report_template.md` - Standardized template for recording security incidents.
