# Network Security & Hardening Checklist

## Perimeter Defenses
- [ ] Ensure all perimeter firewalls have up-to-date rule sets.
- [ ] Restrict inbound remote desktop (RDP) and SSH access exclusively to secure VPN tunnels.
- [ ] Monitor Secure Web Gateway (SWG) logs for anomalies or unauthorized data exfiltration attempts.

## Endpoint Security
- [ ] Verify that Endpoint Detection and Response (EDR) agents are active on 100% of corporate endpoints.
- [ ] Schedule weekly automated vulnerability scans across all subnet ranges.
- [ ] Enforce automated OS patching and software updates.
