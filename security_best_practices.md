# Enterprise Security Best Practices

## 1. Password Hygiene
- Use strong, unique passphrases containing a mix of letters, numbers, and symbols.
- Never reuse passwords across corporate and personal accounts.
- Store all credentials securely using an approved enterprise password manager.

## 2. Multi-Factor Authentication (MFA)
- Enable MFA on all corporate email, cloud platforms, and internal portals.
- Report any unexpected or unauthorized MFA push notifications immediately to the SOC.

## 3. Safe Browsing & Email Habits
- Inspect sender email addresses carefully before clicking any links.
- Avoid downloading unverified software, attachments, or scripts from untrusted sources.
